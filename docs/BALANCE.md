# BALANCE — CPU 自己対戦の記録

DESIGN.md §6 の自己対戦シミュレーター（`dotnet/Edgewise.Sim`）による計測結果。Phase 2 のベースライン（CPU 3 難易度の強さと、原作ルールの先攻有利・引き分け率）を記録する。
Pivot のトークン数などの調整（Phase 4）は、この表を基準に差分で判断する。
**Pivot の先攻有利の修正（Phase 3c）は「Phase 3c: Pivot の非対称化」、星図巡りの進行バランス（Phase 5a）は末尾の「Phase 5a: 星図巡りの進行バランス」**。

## 測定条件

| 項目 | 値 |
|---|---|
| 局数 | 1 行あたり 1000 配牌 × 席交代 2 局 = **2000 局**（配牌は 50 枚から重複なしで 5 枚ずつ。Random ON は 8 枚ずつのデッキ） |
| 乱数 | `--seed 2026`。配牌・先攻・各手の AI の seed はすべてこれで決まり、スレッド数によらず同じ結果になる（時間の列を除く） |
| マシン | 12th Gen Intel Core i7-12700F（20 論理コア）、Windows 11（10.0.26200）、.NET 9.0.15、Release ビルド、20 スレッド並列 |
| ルール | Basic = 基本のみ（Open ON）／ Same+Plus+Combo（Open ON）／ All = Random・Same・Same Wall・Plus・Combo・Elemental・Sudden Death・Pivot（Open ON）／ Basic (Open OFF) |
| 勝率 | 引き分けを除いた勝率。[ ] は Wilson 95% 信頼区間 |

AI のパラメータ（`Assets/Game/Core/AI/AiProfile.cs`）:

| 難易度 | 1 手のノード予算 | 深さ | 決定化の世界数（Open OFF） | ノイズ | 見落とし | その他 |
|---|---:|---|---:|---:|---:|---|
| Easy | 2,000 | 1 手 | 1 | ±150（1.5 枚分） | 40%（Same/Plus/Combo を無視して読む） | 置換表なし |
| Normal | 30,000 | 3 手 | 3 | ±40 | 0% | 置換表 2^14 |
| Hard | 400,000 | 制限なし（反復深化で終局まで） | 8 | 0 | 0% | 置換表 2^18、ルートの窓 150、同値手の選び分け（TieBreakDepth 2） |

途中局面は「スコア差 ＋ 手番ボーナス 50 ＋ 手札の辺の合計×3 ＋ 露出した辺のリスク（相手の手札で取られうるカード 1 枚 −40、相手の手番なら −60、辺の値による一般リスク 0〜−20）＋ Pivot トークン 1 個 15」。


`oracle=1`（相手の手札を見せる）と `truepool=1`（決定化の候補を相手の本当の手札だけにする）は計測専用で、ゲームでは使わない。

## 結論（要約）

1. **Hard vs Easy**（引き分け除く Hard 勝率）: Basic 96.4% [95.3, 97.2]、Same+Plus+Combo 98.0% [97.2, 98.5]、All 99.2% [98.7, 99.5]、**Basic (Open OFF) 89.6% [87.9, 91.0]**。
   4 条件の合計は 6507 勝 264 敗 = **96.1%**。Open ON の 3 条件は 95% 以上を満たすが、**Open OFF は 95% に届いていない**（下の「Open OFF の情報の価値」を参照）。
2. **Hard vs Normal**: 全条件で Hard が有意に勝ち越し（信頼区間の下限がすべて 50% を大きく上回る。最も小さい Open OFF でも 65.6% [62.9, 68.2]）。
3. **Normal vs Easy**: 83.8%〜97.3%。3 段階の強さの順序は全条件で Hard ＞ Normal ＞ Easy。
4. **先攻有利・引き分け率（Hard vs Hard）**: Basic は先攻 55.3% [52.1, 58.5]・引き分け 53.2%、Same+Plus+Combo は 53.3%・60.6%、Open OFF は 49.7%・42.1%。
   （Open ON の Hard 同士はノイズがなく決定論的なので、席を入れ替えた 2 局が鏡写しになり A の勝率はちょうど 50% になる。見るべきは先攻勝率と引き分け率。）
   強い CPU 同士だと**引き分けが目標（15〜35%）より多い**。All（Pivot・Sudden Death 込み）は引き分け 3.5% だが**先攻勝率 68.2% [66.1, 70.2] と先攻が強すぎる**。Phase 4 の調整対象（下の「Phase 4 への申し送り」）。
5. **読み切り**: Open ON なら Hard は **3 手目から 100% 終局まで読み切る**（Basic・Same+Plus+Combo）。Pivot 込みの All は 4 手目で約 45%、**5 手目から 100%**。Open OFF（8 世界）は 4 手目から全世界で読み切る。
   読み切った時点で「勝ち」と予想した局はすべて実際に勝っている（総当たり検証と合わせて、読み切りの正しさの裏付け）。
6. **思考時間**: WebGL（Chrome、i7-12700F）で Hard の 1 手は平均 0.13 秒・最大 0.32 秒、思考中も 59〜60 FPS（1 フレーム 6 ms 予算）。CPU を 4 倍遅くしたエミュレーションでも最大 1.34 秒・最低 25〜40 FPS（30 FPS 未満のフレームは 1171 中 0〜1）。

### Open OFF の情報の価値（Hard vs Easy が 95% に届かない理由）

- 同じ Hard に相手の手札を見せると（oracle）、Open OFF でも 96.7%（Basic）・98.5%（Same+Plus+Combo）・99.5%（All）になる。決定化の候補を相手の本当の手札だけにしても（truepool）97.8% なので、**探索・決定化の仕組みは正しく、差は「相手の手札が見えない」ことによる**。
- 決定化（PIMC: 世界ごとに完全情報として読み、各手の評価を平均）は、世界数を 8 → 16 → 32 → 64 に増やしても、予算を 2 倍にしても 85〜90% で頭打ちになった。
  特に Same / Plus は「相手がちょうどその値のカードを持っているか」で結果が大きく変わるため、見えない情報の影響が大きい（Basic 89.6% に対し Same+Plus+Combo 84.7%）。
- PIMC の限界（各世界で「相手も自分も全部見えている」前提で読む、いわゆる strategy fusion）を超えるには、情報集合単位の探索（IS-MCTS など）や相手の手札の推定が必要で、Phase 2 の範囲を超えると判断した。
- 予算を 2 倍（800k）にすると Open OFF の Hard 同士では 52.8〜54.8% と少し強くなる（Open ON では差なし）。思考時間の余裕（下記）との兼ね合いで既定値は 400k のままにした。

### 同値手の選び分け（TieBreakDepth）

ミニマックスは「相手も最善を尽くす」前提なので、読み切った結果が同じ（例: すべて引き分け、すべて負け）の手を区別できない。
読み切った結果が引き分けか負けのときは、同じ結果になる手の中から「2 手読み（途中局面の評価）の値」が最も良い手を選ぶようにした。
これで Basic の Hard vs Easy は 91.9% → **96.4%**（負けが 115 → 56）。上の「最初に読み切った時点の予想と実際の結果」の表のとおり、Hard の負けはすべて「読み切った時点ですでに理論上負け」の局で、
そこから相手のミスで勝ち・引き分けに持ち込む割合が上がった。勝ちが読み切れているときは何もしない（最大差で勝つ手を選ぶ）。
なお 2000 万ノードで 1 手目から完全に読み切る Hard（選び分けなし）は、Basic で 88.8%（別 seed の 300 配牌。同じ配牌で 40 万ノードの Hard は 95.0%）と**かえって弱かった**（同値手を区別できないため）。

## 予算の決め方

- **Hard 400,000 ノード**: 強さは 40 万で頭打ち（80 万 vs 40 万は Open ON で 49.7%、10 万 vs 40 万は 41.8% と弱い）。WebGL の実測で最大 0.3 秒、4 倍遅い端末でも 1.3 秒に収まる値。Open OFF では 80 万の方が少し強い（52.8〜54.8%）ので、遅い端末を切り捨ててよいなら上げる余地がある。
- **Normal 30,000 ノード・3 手読み・3 世界**: 3 手読みは平均 7 千ノード程度で収まり、Pivot 込みでも予算 3 万で足りる（Normal の性格は予算でなく深さで決めた）。
- **Easy 2,000 ノード・1 手読み・ノイズ ±1.5 枚・見落とし 40%**: 1 手読みなので予算は形式的。ノイズと見落としで「ときどき悪手を指すが、目先の取り合いはする」強さにした（Normal に 84〜97% 負ける）。
  95% の条件を満たすために Easy を弱くすることはしていない（ノイズ・見落とし率は最初に決めた値のまま。評価関数の改良は全難易度に共通）。

## Phase 4 への申し送り

- **引き分けが多い**（強い CPU 同士で Basic 53%、Same+Plus+Combo 61%）。原作ルール由来の性質で、目標 15〜35% より多い。
- **All（Pivot・Sudden Death 込み）は先攻が強すぎる**（Hard 同士で先攻 68.2%）。Sudden Death の再戦は先攻が交代するが、それでも本戦の先攻が有利。Pivot トークン数（後攻だけ 1 個多くする等）で調整する候補。
- **原因の切り分け（監査時の追加計測、Hard 同士・400 配牌×席交代・seed 99、先攻勝率は引き分け除く）**: 主因は **Pivot**。

  | ルール | 先攻勝率 | 引き分け率 |
  |---|---:|---:|
  | Basic (Open) | 62.6% [57.6, 67.5] | 54.5% |
  | Pivot (Open) | **80.6% [76.7, 84.0]** | 43.3% |
  | Sudden Death (Open) | 57.3% [53.7, 60.9] | 11.5% |

  再現: `dotnet run -c Release --project dotnet/Edgewise.Sim -- --match hard:hard --rules basic,pivot,suddendeath --deals 400 --seed 99`
  Pivot は看板メカニクスなので、Phase 4 の最優先課題とする（候補: 後攻のトークンを多くする／先攻の 1 手目は回転不可／トークン数を 1 に減らす）。
- Pivot の使用タイミング: Hard は序盤にほとんど使わず（1 手目 3〜4%）、6 手目以降に 30〜47% で使う。Easy は序盤から乱用する（2〜4 手目で 50% 超）。

## Phase 3c: Pivot の非対称化

DESIGN §3-1「調整の方針（Phase 3c）」。Pivot トークンを先攻・後攻で別々に設定できるようにし（`GameConfig` の `pivotTokensFirst` / `pivotTokensSecond`。既定値は TS 版と同じ 2/2 で、ゴールデン突き合わせはそのまま通る）、候補を Hard 同士の自己対戦で比べた。

### 結論

**ゲーム本体の既定値: 先攻 1・後攻 2。ただし Sudden Death ON のときは 1・1**（`GameConstants.MatchPivotTokens(rules)`）。

| ルール（Hard 同士、Open ON） | トークン | 先攻勝率（引き分け除く）[95% CI] | 引き分け率 | Pivot なしの先攻勝率 / 引き分け率 |
|---|---:|---:|---:|---:|
| Basic + Pivot（seed 2026） | 2/2（従来） | 74.8% [72.2, 77.3] | 44.2% | 55.4% / 52.9% |
| Basic + Pivot（seed 2026） | **1/2** | **48.2% [45.0, 51.4]** | 52.8% | 55.4% / 52.9% |

| 全部入り（seed 2026） | 2/2（従来） | 68.1% [66.0, 70.2] | 3.9% | 52.0% / 14.4% |
| 全部入り（seed 2026） | **1/1**（Sudden Death ON） | **53.0% [50.7, 55.3]** | 8.3% | 52.0% / 14.4% |

合格条件（§3-1）との照合:
- **先攻勝率 45〜55%**: Basic+Pivot 47〜48%、全部入り 53% で両方とも満たす（2 つの seed で確認）。
- **引き分け率を Pivot なしより増やさない**: 全部入りは 14.4% → 8.3%（減る）。Basic+Pivot は 52.8% / 53.1% で、Pivot なし（52.9% / 51.7%）と 2 seed 合わせて +0.6 ポイント。信頼区間（各 ±2.2 ポイント）の中の差で、「同等」と判断した（従来の 2/2 の 44% よりは増えるが、それは先攻が勝ち切っていた分が引き分けに戻ったもの）。
- **Pivot が使われ続ける**: Hard が 1 局で 1 回以上回転する割合は、Basic+Pivot で先攻 70% / 後攻 75%（2/2 は 79% / 69%）、全部入りで 86% / 88%（2/2 は 90% / 86%）。ほとんど落ちない。
- **Pivot なしでも残る先攻有利の打ち消し**: Basic は Pivot なしで先攻 55% だが、1/2 の Pivot を入れると 48% になり、Pivot が先攻有利を打ち消す側に回る（§3-1 の「優先」の条件）。
- **Hard vs Easy は落ちない**（seed 2026、1000 配牌）: Basic+Pivot 97.8% → 98.0%、全部入り 99.2% → 99.7%、全部入り Open OFF 90.2% → 90.2%。Hard vs Normal も 81.1% → 84.1%、91.5% → 91.8%、70.3% → 71.6%。

### 候補の比較（Hard 同士・Open ON・seed 2026・2000 配牌 × 席交代）

先攻勝率は「配牌ごとに 1 局だけ数えた独立な標本」の Wilson 95% 信頼区間（下の「信頼区間について」）。使用率 = その役割の Hard が 1 局で 1 回以上回転した割合（先攻 / 後攻）。

| トークン 先攻/後攻 | Basic+Pivot 先攻勝率 | 引き分け | 使用率 | 全部入り 先攻勝率 | 引き分け | 使用率 | 判定 |
|---|---:|---:|---:|---:|---:|---:|---|
| Pivot なし | 55.4% [52.2, 58.5] | 52.9% | — | 52.0% [49.6, 54.4] | 14.4% | — | 基準 |
| 2/2（従来） | 74.8% [72.2, 77.3] | 44.2% | 79% / 69% | 68.1% [66.0, 70.2] | 3.9% | 90% / 86% | ✕ 先攻が強すぎる |
| 1/1 | 55.6% [52.4, 58.8] | 54.6% | 65% / 68% | 53.0% [50.7, 55.3] | 8.3% | 87% / 88% | Basic+Pivot ✕（先攻 55% 超・引き分け増）、全部入り ○ |
| 1/2 | 48.2% [45.0, 51.4] | 52.8% | 71% / 75% | 43.7% [41.5, 46.0] | 5.3% | 86% / 91% | Basic+Pivot ○、全部入り ✕（後攻が強い） |
| 1/3 | 53.6% [50.6, 56.6] | 47.4% | 69% / 77% | 33.5% [31.4, 35.6] | 4.1% | 86% / 94% | 全部入り ✕ |

400 配牌の予備実験（点推定のみ）: 2/3 は Basic+Pivot 78.4%・全部入り 60.7%（後攻を増やしても先攻 2 個の有利は消えない）、0/1 は 13.8%・16.6%、0/2 は 6.0%・4.8%（先攻 0 個は後攻が強すぎる）。
**先攻の持つ数が支配的**で、先攻 2 個では後攻を何個にしても 60% を超え、先攻 0 個では 20% を切る。先攻 1 個が唯一の候補で、後攻の数で微調整する形になった。

「先攻は 1 手目に回転できない」は実装して比べるまでもないと判断した: 従来の 2/2 で Hard が 1 手目に回転する割合は Basic+Pivot 0.3%・全部入り 2.7%（400 配牌の予備実験）で、1 手目を禁じても 75〜80% の先攻有利はほとんど動かない。

### なぜ Sudden Death の有無で変えるのか（原因の切り分け）

1/2 は全部入りでだけ後攻に偏る（43.7%）。ルールを 1 つずつ外して比べると（seed 2026、1000 配牌）、原因は **Sudden Death** だった。

| ルール | 1/1 の先攻勝率 | 1/2 の先攻勝率 |
|---|---:|---:|
| Same+Plus+Combo+Pivot | 55.9% [49.9, 61.8] | 47.6% [42.8, 52.4] |
| 全部入りから Sudden Death を外す | 57.6% [51.9, 63.1] | 49.0% [44.1, 53.9] |
| Pivot + Sudden Death | 54.3% [51.0, 57.4] | 43.5% [40.3, 46.7] |
| 全部入り | 53.9% [50.6, 57.1] | 41.9% [38.8, 45.0] |

Sudden Death の再戦では先攻が入れ替わり、トークンは持ち越す（DESIGN §2）。1/2 だと、本戦の後攻が再戦で「先攻 ＋ トークン多め」になる。実際、再戦までもつれた局の本戦の先攻の勝率は 1/2 で 36.7〜37.3%（1/1 は 52〜53%）で、本戦だけで決着した局（49%）より大きく下がる。
Sudden Death 自体が先攻を交代させて先攻有利を打ち消す（Pivot なしの Sudden Death で 50.2%）ので、Sudden Death ON のときは後攻に上乗せしない 1/1 がちょうどよい。

### 選んだ理由（ゲームとしての面白さ）

- **先攻の 1 個は「いつ切るか」が一番重い**: 2 個あると後半に 2 回とも使えて、最後の 1 手（先攻が打つ 9 手目）の回転まで含めて先攻が勝ち切りやすかった。1 個なら、序盤の取り合いに使うか最後まで取っておくかの選択になる。
- **後攻の 2 個は逆転の手段**: 後攻は手数が 1 手少ない代わりに回転が 1 回多い。Hard の使用率は後攻 75% と高く、Pivot の使い道が残る。
- 1/3 は先攻勝率・引き分けとも悪くないが、後攻が 4 手中 3 手を回せてトークンの希少さ（駆け引き）が薄れ、全部入りでは 33% と崩れるので採らなかった。
- 1/1 一律は Sudden Death なしで先攻 56% と引き分けの増加が残るので採らなかった。
- ルールで数が変わるのは、対戦設定画面の Pivot の説明文（「先攻 1 回・後攻 2 回」／ Sudden Death ON で「1 回ずつ」）と、対戦中のトークン表示（★☆）で伝える。

### 信頼区間について

Open ON の Hard 同士はノイズがなく、席を入れ替えた 2 局が鏡写しになる（同じ配牌・同じ先攻なら同じ手順）。2 局を独立とみなすと信頼区間が √2 倍狭く出すぎるので、Phase 3c からは「配牌ごとに 1 局だけ数えた」先攻勝率と区間を別の表に出し、合否はそちらで判断した（Sim の出力「先攻勝率（配牌ごとに 1 局だけ…）」）。2000 配牌で ±2〜3 ポイント。

DESIGN §12-9。星図巡り（一人用モード）の 12 人の相手について、「その時点の標準的な手持ち」で組んだ最善デッキのプレイヤー役 AI（Normal）が勝つ割合を測り、§12-9 の目標に入るまで相手の持ちカードと AI の強さを調整した。

調整は 3 段階: 初回（引き分けを除いた勝率の目標）→ 引き分け対策（全対戦に対する勝ち・負けの追加目標）→ **主戦に Sudden Death（主の目標は Sudden Death 込みの全対戦比）**。今のデータは 3 段階目の後の値。

#### 分かったこと（なぜ引き分けを除いた勝率と両立しないか）

- **引き分けはプレイヤー役（Normal）の「守りの結果」**。相手を強くすると（カードを強くする、読みを深くする、Hard にする）、プレイヤー役の負けはほとんど増えず、勝ちが引き分けに変わる。例: マーロウを Hard にして持ちカードを弱くしても、勝 12 / 分 64 / 負 24%。カードの辺を尖らせても（hollowshade・cinderdrake などを混ぜる）引き分けは減らなかった（ミラで 44% のまま）。性格（取れる枚数・守りの重み）を変えても同様。
- **引き分けを減らせたのは相手のノイズだけ**で、そのとき減るのは主に「負け」ではなく「引き分け」なので、引き分けを除いた勝率は 80〜93% に上がる。
- 目標どうしの関係: 星域 1 の相手の「勝ち ≥55%・負け ≤15%」と「引き分け除く 70〜80%」を両方満たすには、負けが 13.75% 以上かつ引き分けが 31% 以下である必要がある。基本ルール（Open のみ）でプレイヤー役が Normal だと、負けを 10% 以上にすると引き分けも 40% を超え、両立する組み合わせは見つからなかった。

主な発見と手当て:

1. **標準的な手持ちは「上限」に届かない**。1 人に勝つごとに 1 枚なので、プレイヤーのデッキは「直近にもらった 3 枚＋はじめの手持ち 2 枚」程度で、星域 2 では Lv15〜21（上限 25）。設計表の Lv 帯（星域 2 の相手は Lv3〜7）のままでは相手が一方的に強い。
   → 相手の持ちカードを「**ご褒美の 1 枚（プレイヤーの今の最強より 1 段上）＋それより弱いカード**」の形にした。ご褒美が次の相手で使うカードになり、デッキが 1 人ごとに 1 段ずつ育つ。星域 1・2 の相手は Lv1〜6、星域 3・4 は設計表に近い Lv4〜10。
2. **フリー対戦の Easy は Normal に対して弱すぎる**（同じ強さの手札でも 9 割負ける。ノイズ ±150・見落とし 40%）。カードを 2 段強くしても 88%。
   → 星図巡りの Easy は「1 手先・ノイズ ±40・見落としなし」（`CampaignAi.Easy`）、Easy+ は「2 手先・ノイズ ±60」（`CampaignAi.EasyPlus`）にした。
3. **Normal+（深さ 4）は Normal に対して 8 割以上勝ち、段階として大きすぎた**（セレストの手札をプレイヤーより弱くしても、プレイヤー役の勝率は 3〜24%）。
   → Normal+ は「Normal からノイズを除き、決定化の世界を 4 つにしたもの」にした（Normal との差は小さいが、性格で個性を出す）。
4. **基本ルール（Open のみ）は引き分けが多く、引き分けを除いた勝率が手札の差に敏感**。マーロウの DeckSlack を 3 → 2 にするだけで 67% → 49% に動いた。手札 1 枚の入れ替え（coglet → scalefry）で 58% に合わせた。
5. **星界の門（Pivot＋Sudden Death＋Open OFF）の Hard は持ちカードを弱くしても勝率が下がらない**（ローレルのデッキを Lv43 → 35 にしても 57〜63% 勝つ）。
   → ローレルは Hard の読み方（読み切り・ノイズなし）のまま予算を 25,000 ノード・世界 4 に絞った（`CampaignAi.HardLight`。表示は Hard のまま）。
6. **Lv10 の配置**: 「Lv10 は星域 4 だけ」「イオは 2 枚」「50 枚すべてを誰かが持つ」を同時に満たすには、残りの 3 枚をテオ・ローレルが持つ必要がある（設計表の Lv7〜9 を外れる）。ローレルに 2 枚持たせると強すぎたので、**テオ 2 枚（pegasion・ophiwyrm）、ローレル 1 枚（ursamaw）、イオ 2 枚（andromede・sextantor）**にした。
7. イオは DeckSlack 1（ほぼ常に最強のデッキ）、テオは 5（デッキがばらつく）。ヴェイルは nocturnis（アストラ戦で使うご褒美）を残したまま forgecolossus を corvusarc に替えて 60% にした（ご褒美を変えると、その後の 3 人の標準的な手持ちが変わり、星域 3・4 全体が 5〜10 ポイント動くため）。

### 性格をつけても難易度の順は崩れない（§12-5）

各相手の AI（性格つき）とフリー対戦の Easy / Hard を、**プレイヤー役と同じ Normal** と戦わせた（ランダムな配牌、300 配牌 × 席交代、seed 2026）。引き分けを除いた勝率（**初回の AI での値**。星域 1・2 の AI を引き分け対策で変えた後の値は「引き分け対策」の節）:

| AI | 星域 1 のルール（Open のみ） | 星域 3 のルール（Open OFF・Elemental・Same・Plus・Combo） |
|---|---:|---:|
| フリー対戦の Easy | 9.0% | 14.7% |
| ミラ（Easy / 素直） | 14.7% | 26.5% |
| オルド（Easy+ / 角・端の守り） | 17.4% | 25.9% |
| マーロウ・リーフ・ユンとシア（Normal） | 48.5〜51.7% | 45.0〜54.7% |
| セレスト・ノア（Normal+） | 58.6〜58.7% | 43.8〜47.2% |
| ヴェイル（Hard- / 揺らぎ大） | 69.1% | 49.0% |
| テオ（Hard- / Pivot 早切り） | 76.4% | 57.1% |
| ローレル（Hard 2.5 万ノード / 守り型） | 74.6% | 51.5% |
| アストラ・イオ・フリー対戦の Hard | 77.9% | 60.7% |

Easy 系（15〜27%）＜ Normal 系（44〜59%）＜ Hard 系（49〜78%）の順は両方のルールで保たれる。
ただし星域 3 のルールでは、Normal+ の 2 人（連鎖重視・属性重視のボーナス）と、揺らぎ大のヴェイルは Normal と同程度まで下がる（性格は強さと引き換えに個性を出す）。Hard（同点の手の間の好みだけ）の性格は強さを変えない。

### 性格の効き方（`dotnet test` の PersonalityTests の出力）

性格のボーナスはルート局面の手の選択にだけ足す（探索の中身・評価関数は変えない）。「その性格が好む手」が 1 つ以上あり全部ではない局面で、好む手を選んだ割合:

| 性格（AI） | 性格なし → あり |
|---|---:|
| Same 狙い（Normal、Same＋Same Wall） | 21.9% → **61.2%**（242 局面） |
| Plus 狙い（Normal、Plus） | 32.8% → **72.4%**（116 局面） |
| 角・端の守り（Easy、基本） | 角に置く 38.4% → **66.7%**（396 局面） |
| 属性マス重視（Normal、Elemental） | 一致するマスに置く 8.7% → **41.3%**（206 局面） |
| Pivot 早切り（Normal、Pivot） | 回転して置く 39.4% → **92.1%**（241 局面） |
| 素直（Easy、基本） | 1 手で裏返す枚数 0.80 → **0.94** |
| 揺らぎ大（Hard-） | 同じ局面で seed を 8 通り変えたときの手の種類（40 局面の合計）78 → **128** |
| 守り型（Hard、同点の手の間だけ） | 読み切った 104 局面のうち 21 局面で、同じ値の別の手を選んだ（値は常に最善） |

### 気づいた点（5b・5c への申し送り）

- **星域 1・2 は引き分けが多い**（初回 43〜59%、引き分け対策の後も 33〜52%）。基本ルールと Same/Plus だけでは強さの近い同士が引き分けやすい。対策と、ルール変更の提案は「引き分け対策」の節。
- **プレイヤー役の Normal は人間の初心者より強いと思われる**。面接官が初見で遊ぶと、表より勝率は下がる見込み。
- 星界の門は Sudden Death で引き分けがほぼなくなる（0〜0.2%）。
- Open OFF で、プレイヤー役は相手の持ちカード（7〜8 枚）を知っている前提で測った。初対戦（まだ「？」が多い）では少し不利になる。
